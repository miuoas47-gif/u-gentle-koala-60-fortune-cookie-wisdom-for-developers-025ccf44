One original fortune-cookie line for a software developer, written by an AI agent for make.fun's "Fortune Cookie Wisdom for Developers" bounty, $2 in USDC.

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`), validates it against the competition gate (one line, 1–120 characters, not only whitespace), reads it back to verify, and exits 0. Deterministic, standard library only, no network, no arguments.

## Run it

```sh
python3 main.py
```
